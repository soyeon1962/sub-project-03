## 프로젝트 개요
이 프로젝트는 React를 활용하여 사용자 친화적인 웹 애플리케이션을 제작한 서브 프로젝트입니다. 컴포넌트 기반 구조와 React의 상태 관리를 통해 효율적인 개발이 가능하도록 설계되었습니다.

## 사용 기술
- **React**
- **HTML**
- **CSS**
- **JavaScript**

## 주요 기능
- **동적 데이터 처리**: React 상태 관리를 통해 사용자 입력 및 동작에 따라 동적으로 UI 업데이트
- **컴포넌트 재사용**: 반복적인 요소를 컴포넌트화하여 유지보수성과 확장성 향상
- **SPA (Single Page Application)**: React Router를 사용하여 페이지 전환 시 화면 리로드 없이 부드러운 경험 제공
